# じゃんけんゲーム

## プロジェクト概要
このプロジェクトは、コンピューターとじゃんけんをして勝敗を楽しむシンプルなゲームです
Python版とJava版があります
プログラムを実行すると、コンピューターがランダムに手を出し勝敗を判定します。

## 実行環境
- Python版：Python3.x
- Java版：Java11以上推奨

## 実行方法
### Python版：janken.py
1. ターミナル(またはコマンドプロンプト)でフォルダに移動
2. 以下を実行
```
Python janken.py
```
### Java版：janken.java
1. ターミナル(またはコマンドプロンプト)で移動
2. コンパイル
```
Javac Java.janken
```
3. 実行
```
Java janken
```
## 遊び方
1. プログラムを実行すると、手の選択肢が表示されます。
